### 🚀 Selected Projects

**[VocalWell](https://github.com/hardik-thapar/vocalwell_backend)**
End-to-end voice pathology detection platform — audio preprocessing, deep learning models, FastAPI backend, PostgreSQL database, Dockerized deployment.

**[EEG Alzheimer's Detection](https://github.com/hardik-thapar/eeg-alzheimer-detection)**
Research pipeline for Alzheimer's disease detection from EEG signals using deep learning, with subject-level cross-validation and multi-dataset evaluation.

**[DengCast](https://github.com/hardik-thapar/dengcast-dengue-forecasting)**
Leakage-aware epidemiological time-series forecasting using gradient boosting, CatBoost, and recursive autoregressive modeling on climate-driven dengue data.

**[FastAPI Patient Management System](https://github.com/hardik-thapar/FastAPI-Patient_Management_System)**
A project implementing FastAPI, Pydantic, and asynchronous methods for a patient management backend.
